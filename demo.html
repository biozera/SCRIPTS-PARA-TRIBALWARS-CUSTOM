🗡️ Tribal Wars Intel Overlay - Demo

Features Overview

  • Attack Mode: Toggle to enable special visual indicators for villages
  • Population-Based Colors: Automatic color coding based on survivor population
  • Customizable Colors: Personalize colors for each population range
  • Recent Reports Filter: Filter out old intelligence based on update date

How to Install

  1. Install Tampermonkey or another userscript manager
  2. Open tribalwars-intel-overlay.user.js in your userscript manager
  3. Click "Install" when prompted
  4. Navigate to your Tribal Wars game
  5. Look for the ⚙️ Intel Settings button in the top-right corner

Technical Details

Data Source: tw_village_intel_latest table

Key Columns:

  • pop_survivors - Population count for color classification
  • updated_at - Timestamp for filtering recent reports
  • village_id, x, y - Village identification

Storage: Settings persist using GM_setValue/GM_getValue
